# A custom Jekyll theme for GitHub Pages

A clean, blog-focused Jekyll site with:

- 🌗 **Dark & light mode** with a toggle (remembers your choice, respects your OS default)
- 🟦 **Muted palette** tuned for comfortable reading in both modes
- 🧱 **Tile homepage** - each post shows a picture + description and links to the full article
- 👤 **About page** you can personalize
- 🔎 **Client-side search** over all post text (works on GitHub Pages, no plugins needed)
- 📱 Responsive layout, RSS feed, and SEO tags

## Quick start (local preview)

You need Ruby + Bundler installed. Then run:

```bash
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000>.

## Publish to GitHub Pages

1. Create a GitHub repo and push these files to it.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick your
   branch (e.g. `main`) and the `/ (root)` folder, then **Save**.
4. Your site appears at `https://<username>.github.io/<repo>/` in a minute or two.

### Important: baseurl

- **Project site** (`username.github.io/my-repo`): set `baseurl: "/my-repo"` in `_config.yml`.
- **User/org site** (repo named `username.github.io`): leave `baseurl: ""`.

## Make it yours

| What | Where |
|------|-------|
| Site title, author, description | `_config.yml` |
| Header colors / palette | top of `assets/css/style.scss` (the `--accent` variables) |
| About page text & photo | `about.md` and `assets/images/avatar.svg` |
| Add a post | new file in `_posts/` named `YYYY-MM-DD-title.md` |
| Tile / banner image for a post | `image:` field in the post's front matter |

### Post front matter template

```yaml
---
title: "My New Post"
date: 2026-07-08 09:00:00 +0000
description: "One-line summary shown on the homepage tile."
image: /assets/images/my-photo.jpg
tags: [tag1, tag2]
---
```

Everything below the front matter is written in Markdown.

## How search works

`search.json` is generated by Jekyll into a JSON index of every post. `assets/js/search.js`
fetches it in the browser and filters as you type - so it runs entirely client-side and is
fully compatible with GitHub Pages.
